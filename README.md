# 🍫 Motor de Formulación Agroindustrial

**Optimización de Costos y Calidad en barras energéticas**

Motor inteligente que combina métodos numéricos e inteligencia artificial
para encontrar la formulación óptima de barras energéticas.

## 🚀 Características

- ⚙ Gauss-Jordan
- 📐 Programación Lineal
- 🤖 Random Forest
- 📊 5 gráficos interactivos
- 📄 Exportación a PDF
- 📧 Envío por correo
- 🌐 100% web

pip install -r requirements.txt
